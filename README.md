# weldspan

Weld structured JSON span payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/weldspan/

## Install / run

```bash
git clone https://github.com/theworker02/weldspan.git
cd weldspan
node src/cli.js
node --test
```
